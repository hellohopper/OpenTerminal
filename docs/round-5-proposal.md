# 下一轮功能提案

状态：已授权按顺序实现，实际交付与限制见 round-5.md。按以下顺序可分别作为一个独立 PR。优先复用现有数据、存储、通知和模拟计算能力。

## 1. 个股研究中心与跨面板跳转（功能 37）

现状：ResearchView 只有 Overview、Chart、Financials、Events、Thesis、Filings、Notes、Alerts；新增估值、SEC 阅读器、财报复盘等仍是独立面板。

首版范围：
- 在个股研究页接入该股票的估值场景、SEC 文档/段落、财报复盘和模拟交易计划。
- 增加按股票聚合的研究时间线，显示论点修订、笔记、估值及复盘记录。
- TODAY 和搜索结果可定位到具体记录或段落；打开面板时保留股票和记录上下文。
- 研究页内保留未提交的笔记，股票切换时明确处理编辑状态。

验收：从 TODAY 的任务直接打开对应记录；AAPL 与 MSFT 的内容不混淆；刷新或重新打开受支持链接可恢复目标记录。相对工作量：中。

## 2. 个人研究全文搜索（功能 38）

现状：命令面板支持股票、面板和工作区，但不能统一搜索个人研究记录。

首版范围：
- 搜索日志、论点、已保存的 SEC 段落/批注、估值场景和财报复盘。
- 按股票、内容类型、日期筛选；展示命中片段、来源和更新时间。
- 从结果跳转到功能 37 提供的具体记录入口。
- 只搜索当前部署已保存的内容；清楚标注 SEC 快照截断范围，删除后搜索结果同步消失。

验收：中文与英文关键词、组合筛选、删除后的结果一致性和私有接口鉴权正常。相对工作量：中。

## 3. 同业基本面对比（功能 39）

现状：COMPARE 侧重价格走势；FINANCIALS 一次分析一家公司。

首版范围：
- 用户选择 2–6 家受支持的美国上市公司，比较收入增长、利润率、现金流、资产负债及可验证的估值指标。
- 支持年度和 TTM 口径；只有完整、互不重叠的四个季度才计算 TTM。
- 每个数值显示财报期间、披露日期、单位和原文出处；不可比较或缺失的数据保持空缺。
- 保存同业组和带日期的比较快照，可将参考值带入估值场景。

验收：不同财年、缺季度、修订财报和负利润情况下不产生误导性的倍数；快照不随实时数据变化。相对工作量：中偏大。

数据基础：现有 SEC Company Facts 接口可复用。SEC 提供公开的公司申报和结构化 XBRL 数据；会计口径可比性仍需应用自行校验。[SEC Developer Resources](https://www.sec.gov/about/developer-resources)

## 4. 投资论点验证与失效监控（功能 40）

现状：论点指标和失效条件主要是自由文本，到期复查依靠日期提醒。

首版范围：
- 在保留文字论点的同时配置结构化条件，例如收入同比、利润率、估值区间或价格条件。
- 首版只支持已有可靠数据能计算的指标和 AND/OR 组合；配置版本与论点版本关联。
- 记录每次评估的观察值、来源时间及“满足/不满足/数据不足”。
- 条件状态变化后进入 TODAY 和通知中心，支持冷却和去重；用户确认后再更新论点状态。

验收：过期或缺失数据不会被当作条件成立；重复检查不重复提醒；论点修改后旧监控结果仍可审阅。相对工作量：中偏大。

## 5. 账户导入与对账中心（功能 41）

现状：现有 CSV 导入主要处理买卖记录，多币种账本还有独立的现金、手续费、分红和换汇事件。

首版范围：
- 提供可保存的 CSV 列映射，覆盖交易、入出金、费用、分红和已执行换汇。
- 用户导入期末持仓/现金快照后，比较账本推导值与对账单，列出数量、现金和币种差异。
- 按来源交易 ID 或规范化行指纹去重，保存导入批次、来源和预览结果。
- 对无后续依赖的批次支持撤销；存在后续依赖时列出冲突并拒绝直接撤销。

验收：重复导入、部分无效行、资金不足、超卖和撤销后的账本一致性得到验证。首版使用用户提供的 CSV，不依赖券商登录或交易接口。相对工作量：大。

## 6. 组合风险规则与再平衡提醒（功能 42）

现状：已有压力分析和再平衡模拟，但缺少持续执行的用户风险规则。

首版范围：
- 用户设置单股/行业权重上限、最低现金比例、目标权重偏离阈值，以及有足够净值记录时的回撤阈值。
- 按明确的组合范围评估，保存违规快照和数据完整性状态。
- 阈值跨越后进入 TODAY；从违规记录打开预填的再平衡模拟。
- 显示当前方案与模拟方案的规则检查结果；处理费用、整股取整及不可交易资产造成的残余偏差。

验收：不完整估值不被判定为达标；提醒去重；资金流与市场回撤区分；模拟不会直接改写实际账本。相对工作量：中偏大。

## 7. 期权持仓与到期管理（功能 43）

现状：STRATEGY 可计算策略收益和风险，但缺少持续记录的合约持仓及其生命周期。

首版范围：
- 为独立模拟账户保存标准美股期权合约的开仓、减仓和平仓，记录合约标识、方向、乘数、费用及到期日。
- 从策略构建器创建模拟持仓，查看按标的汇总的 Delta/Gamma/Theta/Vega 和盈亏。
- 提供到期日历与覆盖检查，过期或缺失报价时保留未估值状态。
- 首版处理多头期权和简单价差；行权、指派由用户确认并记录，调整合约或不支持的合约明确拒绝。

验收：乘数和方向正确；部分平仓后成本与费用可对账；到期后不继续把旧报价当作当前估值。相对工作量：大。

边界依据：期权指派涉及履行合约义务及券商处理流程，不能仅凭到期日和收盘价推断真实指派结果。[FINRA — Understanding Assignment](https://syndication.finra.org/content/trading-options-understanding-assignment)

## 8. 策略样本外验证实验室（功能 44）

现状：回测支持单股票、单组参数和两种策略模板，缺少训练/验证分离与稳定性比较。

首版范围：
- 为已有策略设置有限参数网格，按时间顺序划分训练区间和样本外区间。
- 增加滚动训练/验证，参数选择只读取对应训练窗口；样本外结果独立报告。
- 对比交易成本、滑点和参数邻域变化，展示收益、回撤、交易次数与稳定性。
- 保存数据版本、区间、搜索空间、选择规则和结果；限制任务规模，提供进度和取消。

验收：测试窗口数据不能参与参数选择；相同数据/配置结果可复现；样本不足明确拒绝；不能把回看筛选出的最佳结果冒充样本外表现。相对工作量：大。

## 建议顺序

先做 1–2，减少现有功能之间的跳转和查找成本；接着做 3–4，把研究变成可持续检验的流程；最后依次做 5–8，补齐账户可信度、组合约束和更复杂的模拟验证。各项按上述首版边界独立交付，后续增强另列任务。
